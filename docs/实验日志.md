## 1. 目前进展

- `sar-006` 固定 256 输入实验已完成。最佳权重 `model_best.pth` 在 iter 244999 达到 `AP=67.7707`；最终续训权重 `model_latest.pth` 的评估结果为 `AP=67.7609`。

- `sar-000`～`sar-004` 已按历史训练证据改为独立配置，不再继承其他 YAML。五次历史训练均使用固定 256 输入，对数据执行缩放和裁剪到256。

## 4. 直接训练指令

历史实验和已完成实验禁止原地重新训练。新正式实验应复制当前基线、分配 `sar-007` 或后续未占用编号，并在确认目标目录为空后运行：

```bash
python train_net.py --num-gpus 1 \
  --config-file configs/experiments/sar_ship/<sar-007-new-experiment>.yaml
```

仅当规范运行目录中已有有效 `last_checkpoint` 时恢复同一未完成实验：

```bash
python train_net.py --num-gpus 1 \
  --config-file configs/experiments/sar_ship/<running-experiment>.yaml \
  --resume
```

显式复评 `sar-006` 最佳权重：

```bash
python train_net.py --num-gpus 1 \
  --config-file configs/experiments/sar_ship/sar-006-fixed256.yaml \
  --eval-only \
  MODEL.WEIGHTS runs/sar_ship/sar-006__r18-fpn128-h128-bs25-it254264-fixed256-seed40244023/model_best.pth
```

显式复评历史 `sar-001`：

```bash
python train_net.py --num-gpus 1 \
  --config-file configs/experiments/sar_ship/sar-001.yaml \
  --eval-only \
  MODEL.WEIGHTS runs/sar_ship/sar-001__r18-fpn128-h128-bs16-it397288-scratch/model_final.pth
```

评估不得与 `--resume` 同时使用；权重文件只允许 `model_final.pth`、`model_latest.pth` 或 `model_best.pth`。`inference/instances_predictions.pth` 是逐图预测，不是权重。

### 5.2 历史配置校对方法

`sar-000`～`sar-004` 的证据优先级如下：

1. 首次训练 `log.txt` 的完整配置和实际加载行为；
2. 恢复训练日志与运行目录冻结 `config.yaml` 交叉验证；
3. `metrics.json` 最后一条含 `bbox/AP` 的记录用于最终指标；
4. 运行清单与本文档用于汇总限制和迁移关系。

五份配置不含 `_BASE_` 或 `OUTPUT_DIR`，显式记录模型、数据集、固定 256 输入、裁剪、优化器、Batch、学习率、迭代、milestones、测试与随机种子。`sar-000` 使用首次训练日志中的 ImageNet 权重地址，不采用被失败评估覆盖的冻结权重字段。历史设计缺陷只记录，不追溯修正。

固定 256 配置的含义是：数据映射阶段将图像按 Detectron2 的 resize 规则缩放到固定短边/受限长边，并在启用裁剪时执行相应裁剪。它不筛选数据集，也不是“只训练原本为 256×256 的图片”。本地 SAR 原图恰好均为 256×256，但这与配置语义是两件事。

### 5.3 实验规范

- 正式 ID：`<dataset>-NNN`；测试 ID：`<dataset>-test-NNN`。
- NAME 只包含小写字母、数字和单连字符分隔的词，不包含 AP 或结论。
- 非历史实验必须固定非负 `SEED`，默认 `40244023`。
- `ablation` 必须填写 `BASELINE`、`PURPOSE`、`HYPOTHESIS` 和结构化 `CHANGES`；一次只验证一个概念因素。
- 新训练拒绝非空目标目录；评估写入 `evaluations/<UTC时间戳>/`，不得覆盖历史 `inference/`。
- `SOLVER.CHECKPOINT_RETENTION=latest` 周期覆盖 `model_latest.pth`；启用最佳检查点时用验证指标覆盖 `model_best.pth`，但 `last_checkpoint` 必须继续指向 latest。
- 推荐后续顺序：检测头通道宽度 → backbone → proposal 数 → sample step → 输入尺度/裁剪 → 损失权重。
