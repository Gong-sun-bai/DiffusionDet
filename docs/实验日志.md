# DiffusionDet 实验日志

> 建档日期：2026-07-23
> 适用范围：SAR 船舶检测、PANDA 四类别检测及后续 DiffusionDet 消融实验

## 1. 当前结论

- SAR 历史结果中 `sar-001` 的 `AP=66.94` 最高，但其 `SEED=-1`，只能作为方向性参考，不能充当正式可重复基线。
- `sar-002` 的 `SOLVER.STEPS` 全部大于 `MAX_ITER`，训练未发生计划中的学习率衰减，状态记为 `invalid`。
- MobileNetV4-Small 将完整检测模型压缩到约 7.70M 参数，但相对 `sar-000` 的 AP 下降 9.57；MobileNetV4-Medium 增至 20.58M 后恢复 2.65 AP，仍低于 ResNet-18。
- PANDA 是四类别任务，且含空标注图片；`panda-000` 不得与 SAR 单类别实验直接横向比较。
- 当前机器已恢复 `Difdet` 环境，并完成 `sar-007` Batch 16 / 20 iter 训练冒烟；模型导入、数据注册、构建、反向传播和检查点链路均已验证。冒烟不含 AP，下一步仍必须先完成固定种子的 `sar-005`，然后才开始单因素消融。

## 2. 状态与证据规则

实验状态只使用：

- `planned`：配置与假设已登记，尚未启动；
- `running`：输出目录和运行清单已创建，训练或评估正在进行；
- `completed`：进程正常结束并写出 `result_summary.json`；
- `failed`：运行异常，错误类型和消息已写入清单；
- `invalid`：运行结束但关键设计错误使结果不能作为公平对照。

证据优先级：

1. 实际加载权重、恢复位置和运行行为以 `log.txt` 为准；
2. 指标以 `metrics.json` 最后一条含 `bbox/AP` 的记录为准；
3. 结构以输出目录内冻结的 `config.yaml` 为准；
4. 历史汇总和已知问题以 `experiment_manifest.json` 和本文档为索引；
5. 禁止修改历史 `log.txt`、`metrics.json`、`config.yaml`，禁止用新结果覆盖旧目录。

## 4. 历史实验逐项记录

### `sar-000`：SAR ResNet-50 参考

- 配置：`configs/experiments/sar_ship/sar-000.yaml`
- 结果：`runs/sar_ship/sar-000__r50-fpn256-h256-bs16-it397288-pretrain`
- 基线：无。
- 目的：建立大模型 SAR 精度参考。
- 假设：ImageNet 预训练的 ResNet-50 与 256 通道检测头可提供可靠基准。
- 修改位置：`MODEL.RESNETS`、`MODEL.FPN.OUT_CHANNELS`、`MODEL.DiffusionDet.HIDDEN_DIM`、`MODEL.WEIGHTS`。
- 结论：AP 64.53；参数量和显存明显高于 `sar-001`，当前不优先复跑。
- 限制：`SEED=-1`；后续失败评估覆盖过冻结配置的 `MODEL.WEIGHTS`，原始训练确实加载了 ImageNet 权重，以日志为准。
- 原命令：终端输出未被日志捕获，无法无损恢复；禁止在文档中伪造。

### `sar-001`：SAR ResNet-18 / 128

- 配置：`configs/experiments/sar_ship/sar-001.yaml`
- 结果：`runs/sar_ship/sar-001__r18-fpn128-h128-bs16-it397288-scratch`
- 基线：`sar-000`。
- 目的：验证较小骨干与 128 通道结构的精度/体量平衡。
- 假设：SAR 单类别任务不需要 R50/256 的容量。
- 修改位置：ResNet 深度、FPN/隐藏维度和预训练权重。
- 结论：AP 提高 2.41，参数量减少约 68.8%，是当前最值得复现的方向。
- 限制：同时改了骨干、通道和预训练方式，且 `SEED=-1`，不能把提升归因于单一因素。

### `sar-002`：SAR ResNet-18 / 64

- 配置：`configs/experiments/sar_ship/sar-002.yaml`
- 结果：`runs/sar_ship/sar-002__r18-fpn64-h64-bs64-it99400-scratch`
- 基线：`sar-001`。
- 目的：进一步压缩通道与全连接层。
- 假设：64 通道可继续减小模型并保留可用精度。
- 修改位置：FPN/隐藏维度、ROI FC、Batch 和训练长度。
- 结论：参数降至 17.88M，但 AP 下降 5.98。
- 限制：`STEPS=(278102,357559)` 大于 `MAX_ITER=99400`，无计划降学习率；多项变化耦合，状态为 `invalid`。

### `sar-003`：MobileNetV4-Small

- 配置：`configs/experiments/sar_ship/sar-003.yaml`
- 结果：`runs/sar_ship/sar-003__mnv4-small-fpn64-h64-bs64-it99400-scratch`
- 基线：`sar-000`。
- 目的：探索极小检测模型。
- 假设：MobileNetV4-Small 可显著缩小模型。
- 修改位置：`diffusiondet/mobilenetv4.py` 及 backbone/FPN/hidden 配置。
- 结论：仅 7.70M 参数；AP 54.96，AP75 损失尤其明显。
- 限制：没有推理延迟、吞吐和端侧部署数据，不能由参数量直接推断速度。

### `sar-004`：MobileNetV4-Medium

- 配置：`configs/experiments/sar_ship/sar-004.yaml`
- 结果：`runs/sar_ship/sar-004__mnv4-medium-fpn96-h96-bs50-it119280-scratch`
- 基线：`sar-003`。
- 目的：用更大移动骨干换取精度。
- 假设：Medium 能在仍较小的模型体量下明显恢复 AP。
- 修改位置：MobileNetV4 尺寸、FPN/hidden、Batch 和训练长度。
- 结论：比 Small 增加 2.65 AP，但参数约为 2.67 倍，仍低于 R18。
- 限制：训练延长后 milestones 没按 70%/90% 重算；多次中断恢复。

### `panda-000`：PANDA 四类别参考

- 配置：`configs/experiments/panda/panda-000.yaml`
- 结果：`runs/panda/panda-000__r50-fpn256-h256-bs16-it49063-pretrain`
- 基线：无。
- 目的：建立 PANDA 四类别初始结果。
- 假设：R50 DiffusionDet 能建立可继续优化的四类基准。
- 分类 AP：`feeds=31.66`、`Bamboo_leaves=8.45`、`shoot=6.70`、`Bamboo=6.15`。
- 结论：整体 AP 13.24，类别差异明显，需要先检查分布、空标注和标签质量。
- 限制：任务定义与 SAR 不同；验证集中有空标注图片，不能跨数据集比较。

- 产物：`model_final.pth`、`last_checkpoint`、指标、日志、运行清单和结果摘要齐全；清单状态为 `completed`。

- 结论：当前 RTX 2080 Ti 可用正式基线结构和 Batch 16 启动训练；短运行峰值不等于完整训练最坏情况。
- 复现记录：`docs/RTX2080Ti基线复现记录.md`

推荐顺序：

1. `sar-005`：固定种子基线；
2. 通道宽度：只改 FPN/HIDDEN 这一兼容性耦合因素；
3. backbone：固定检测头宽度和训练策略；
4. proposal 数；
5. `MODEL.DiffusionDet.SAMPLE_STEP`；
6. 输入尺度或裁剪策略，每次只选一个概念因素；
7. 分类、L1、GIoU 等损失权重。

## 6. 新实验登记规范

实验目录由入口自动生成：

```text
runs/<EXPERIMENT.DATASET>/<EXPERIMENT.ID>__<EXPERIMENT.NAME>/
```

要求：

- ID 格式为 `<数据集短名>-<三位序号>`；SAR 的 `000–007` 已占用。
- `EXPERIMENT.KIND` 可为 `historical`、`baseline`、`ablation` 或 `smoke`；`smoke` 只验证运行链路，不得报告为精度结果。
- NAME 只使用小写字母、数字和连字符，不包含 AP 或结论。
- 非历史实验必须固定 `SEED`，默认 `40244023`。
- `ablation` 必须填写 `BASELINE`、`PURPOSE`、`HYPOTHESIS`、`CHANGES`。
- `CHANGES` 每项使用 `配置键: 旧值 -> 新值`。
- 一次实验只验证一个假设；结构兼容所必需的耦合参数可一起调整，但要声明为一个概念因素。
- 新训练拒绝非空目标目录；只有 `--resume` 可复用目录，且 `last_checkpoint` 必须有效。
- 评估必须从命令行显式传入 `model_final.pth`；`instances_predictions.pth` 永远不是权重。
- 评估结果自动写入原实验的 `evaluations/<UTC时间戳>/`，不得覆盖历史 `inference/`。

当前机器以 Batch 16、`BASE_LR=2.5e-5`、`MAX_ITER=397288` 为正式参考。若仅因硬件容量改变 Batch，默认线性缩放学习率，按 Batch 反比缩放 `MAX_ITER` 和 `WARMUP_ITERS`，并将 milestones 设为新 `MAX_ITER` 的 70%/90%。这类适配也必须使用新实验 ID，并完整登记所有联动参数。AMP、输入尺度和模型结构变化均是独立实验因素。具体公式与 Batch 8 示例见 `docs/RTX2080Ti基线复现记录.md`。

历史模型复评示例：

```bash
python train_net.py --num-gpus 1 \
  --config-file configs/experiments/sar_ship/sar-001.yaml \
  --eval-only \
  MODEL.WEIGHTS runs/sar_ship/sar-001__r18-fpn128-h128-bs16-it397288-scratch/model_final.pth
```
